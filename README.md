## Projects

### 🔋 Battery Management System — Simulation & Hardware
> **Major project · GNITS 2024**

Built a complete BMS for a 6S lithium-ion battery pack.
- Designed MATLAB/Simulink model for SOC estimation using active cell balancing
- Implemented overcharge (4.25V), over-discharge (2.50V), and overcurrent (50A) protection
- Hardware implementation using DW01-A (protection IC) + BB3A (cell balancing IC) on 6S 12A BMS module
- Validated circuit behavior with MOSFET switching logic and real battery testing

**Tools:** MATLAB, Simulink, Multimeter, BMS hardware module
